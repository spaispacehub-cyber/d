AHBots 1.0
Target: Paper 1.21.11 + ZelAuction 1.4-rc.1

IMPORTANT:
ZelAuction's discovered createListing method requires a Bukkit Player.
This plugin therefore does NOT create fake Player objects or impersonate accounts.

Build:
  mvn package

Install:
  Copy target/AHBots-1.0.0.jar to plugins/
  Ensure ZelAuction is installed.
  Restart server.

Command:
  /ahbot sell <online-player> DIAMOND 64 50000

The item is generated by the plugin and submitted through ZelAuction's API.
